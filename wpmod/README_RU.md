# openpilot 0.11.1 + WPmod для Jeep WK2 2021 / comma4

Это отдельный вариант официального стабильного openpilot 0.11.1,
ветка `release-mici`, база `70e157462304e5ce7d03ffbec6cb7f45bf347bb7`.
В коде автомобиля изменены 11 строк и удалена одна. Вождение использует
официальную модель и штатные настройки openpilot.

## Поведение

- WK2 2019–2021 с обнаруженным WPmod: снят программный порог 17,5 м/с
  (около 39 mph), запрос LKAS соответствует активному рулению comma.
- WPmod определяется по CAN0: идентификатор 0x4FF, длина 4 байта.
- Без этого признака сохраняется штатный порог скорости.
- Газ и тормоз управляются штатным ACC. Самостоятельное руление при
  неактивном ACC этот вариант не добавляет.
- На полной остановке и до 0,3 м/с руление отключено общим controlsd,
  как в проверенном исходнике sunnypilot. Пауза повторного включения LKAS
  более двух секунд сохраняется.

Для возврата обычного усиления руля при неактивном рулении нужна наша
последняя прошивка отдельной платы WPmod `e001be5a`. Данный пакет меняет
программу на comma4; прошивку платы он не записывает. Маркер платы не
содержит номера её прошивки, поэтому openpilot не может проверить версию.
У новой прошивки WPmod есть предварительная подготовка EPS при включении
на низкой скорости: до трёх секунд без передачи активной команды руля.

## Проверка

Проверены настоящие CarInterface, CarController и CANPacker:
обнаружение платы, ошибочный CAN/длина маркера, другие платформы Chrysler,
руление при низкой скорости, отключение LKAS/момента, пауза повторного
включения, предел момента 261 и нарастание не более 3 за команду,
штатный скоростной гистерезис без WPmod. Всего 8 тестов.

Нативные ARM-компоненты, модель, Panda safety, контроль водителя, обработка
ошибок EPS и общий controlsd сохраняются из официального готового релиза.
Изменения относятся к Python; полной пересборки ARM-компонентов не было.
На comma4 этот вариант ещё не установлен и в автомобиле не проверен.

## Установка

Предпочтительный штатный способ — отдельный GitHub fork и установочная
ссылка comma. Точная ссылка появится после публикации этой ветки.
Пока ссылки нет, удалять установленный sunnypilot не нужно.

Архив содержит проверенные исходники, production.patch, git bundle с
изменениями относительно точной официальной базы, отчёт и SHA-256.
Это пакет подготовки ветки; он не является самостоятельным USB-образом.
Готовые ARM-компоненты установщик получит из дерева официальной базы.
Git bundle требует наличия указанного базового коммита в репозитории.

Для возврата к текущей ветке sunnypilot используется прежняя ссылка:
`install.sunnypilot.ai/release-mici`.
